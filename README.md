# 🛒 Lista de Produtos

Aplicação web simples para cadastro e exibição de produtos em uma tabela.

---

## 📌 Sobre o Projeto

O **Lista de Produtos** é uma aplicação desenvolvida com HTML e JavaScript que permite ao usuário adicionar produtos com nome, código e quantidade, exibindo-os dinamicamente em uma tabela.

Este projeto foi desenvolvido com fins educacionais, com foco em:

- Manipulação do DOM  
- Validação de formulários  
- Interação com elementos HTML  

---

## 🚀 Tecnologias Utilizadas

- HTML5  
- JavaScript  
- (Opcional) Tailwind CSS  

---

## ⚙️ Funcionalidades

- ➕ Adicionar produtos à lista  
- 📋 Exibir produtos em tabela  
- ⚠️ Validação para impedir campos vazios  
- 🔄 Limpeza automática dos campos após adicionar
